📊 Vrinda Store Sales Analysis Dashboard

🔍 Project Overview

This project analyzes sales performance of Vrinda Store using Excel.
The goal is to identify key sales trends, customer behavior, and business insights.

---

📊 Dashboard Features

- Monthly Orders vs Sales Trend
- Sales Distribution by Gender
- Order Status Analysis
- Top Performing States
- Age vs Gender Analysis
- Channel-wise Sales Distribution

🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Slicers

---

📈 Key Insights

- Women contribute around 64% of total sales
- Amazon is the top-performing sales channel
- Maharashtra generates highest revenue
- Adult age group contributes the most orders
- Sales peak in March and decline towards year-end

---

🚀 Business Recommendations

- Focus marketing on female customers
- Increase campaigns during low-sales months
- Expand in high-performing states
- Optimize Flipkart and Myntra channels
